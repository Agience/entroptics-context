# entroptics-llm is now entroptics-context

This package has been renamed. Install the new one:

    pip install entroptics-context

and import `entroptics_context`. Installing `entroptics-llm` 0.1.1 installs `entroptics-context`, and `import entroptics_llm` still works but warns.

Source: https://github.com/Agience/entroptics-context
